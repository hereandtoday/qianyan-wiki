> 发展中国家从劳动力过剩到短缺的转折点，此后工资水平将持续上升，经济进入成熟发展阶段。

## 概述

刘易斯拐点（Lewis Turning Point）是由诺贝尔经济学奖得主阿瑟·刘易斯提出的概念，描述的是发展中国家经济发展过程中的一个关键转折点：当农村剩余劳动力被吸收殆尽后，劳动力从过剩变为短缺，工资开始持续上涨。

## 理论背景

### 刘易斯二元经济模型

刘易斯将发展中国家经济分为两个部门：

1. **传统部门**：农村农业部门，劳动生产率低，存在大量剩余劳动力
2. **现代部门**：城市工业部门，劳动生产率高，工资由市场决定

### 经济发展路径

```
阶段一：劳动力无限供给
├── 特征：大量农村剩余劳动力涌入城市
├── 工资：维持在生存水平，变化不大
└── 格局：资本主导，劳动被剥削

阶段二：刘易斯拐点 ← ← ← 【关键转折】

阶段三：劳动力短缺
├── 特征：用工紧张，工资持续上涨
├── 工资：消费上升 → 储蓄上升 → 投资上升
└── 格局：劳动话语权提升，进入黄金发展期

阶段四：被追赶阶段
├── 特征：工资高企，企业向海外转移投资
└── 挑战：需要产业升级应对竞争
```

## 核心特征

### 越过刘易斯拐点后的变化

| 领域 | 变化 |
|------|------|
| **工资** | 持续上涨，且增速加快 |
| **消费** | 居民消费能力提升，消费升级 |
| **储蓄** | 收入提升 → 储蓄增加 → 资本积累 |
| **投资** | 高储蓄支撑高投资 |
| **出口** | 劳动力成本优势减弱 |
| **通胀** | 工资-物价螺旋可能形成 |

## 中国越过刘易斯拐点的证据

### 时间节点

- **普遍认为**：2010年前后中国越过刘易斯拐点
- **信号**：沿海地区出现"用工荒"，工资加速上涨

### 数据支撑

| 指标 | 趋势 | 说明 |
|------|------|------|
| 农民工工资 | 年均增长10%+ | 持续多年的两位数增长 |
| 劳动年龄人口占比 | 2010年达峰值后下降 | 人口红利开始消退 |
| 求人倍率 | >1，且持续上升 | 劳动力供不应求 |
| 制造业工人工资 | 快速追赶越南、印度 | 成本优势减弱 |

## 三阶段发展框架

| 阶段 | 特征 | 政策重点 | 代表国家 |
|------|------|---------|---------|
| **早期工业化** | 农村劳动力转移，工资停滞 | 财政政策 | 1978年前的中国 |
| **黄金时代** | 越过刘易斯拐点，工资消费双升 | 货币政策 | 当前中国 |
| **被追赶阶段** | 工资高企，产业向外转移 | 财政政策 | 日本、韩国后期 |

## 投资启示

### 消费升级

越过刘易斯拐点后，消费成为经济增长的主要驱动力：

- **必需消费 → 可选消费**：食品饮料 → 旅游娱乐
- **低端 → 中高端**：性价比 → 品质、品牌
- **物质消费 → 服务消费**：购物 → 医疗、教育、旅游

### 产业升级

劳动力成本上升，倒逼企业进行产业升级：

- **自动化**：用机器替代人工
- **高端化**：向产业链上游延伸
- **品牌化**：从代工转向自有品牌

### 投资方向

| 受益方向 | 逻辑 |
|----------|------|
| **消费品牌** | 消费升级驱动品牌崛起 |
| **自动化设备** | 替代人工的生产设备需求 |
| **职业教育** | 劳动力技能提升需求 |
| **高端制造** | 产业升级的核心方向 |

### 风险提示

- 产业过早外迁（制造业流失）
- 工资-通胀螺旋
- 中小企业生存压力加大
