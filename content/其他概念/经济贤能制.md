> 通过自由市场竞争，让具有企业家精神的人获得资源支配权，实现资源的优化配置。

## 概述

经济贤能制（Economic Meritocracy）是与政治贤能制相对应的概念，核心是：在经济领域，通过市场竞争机制，让最有能力的人获得资源、创造价值，而非依赖政府分配或家族传承。

## 理论背景

### 亚当·斯密的看不见的手

- 自由市场是最有效的资源配置机制
- 个人追求私利可以促进社会整体福利
- 竞争机制筛选出最有效率的生产者

### 约瑟夫·熊彼特的创造性破坏

- 经济发展来自企业家的创新
- 创新意味着对旧秩序的"破坏"
- 真正的"贤能"是创新能力，而非存量规模

## 核心特征

| 特征 | 说明 |
|------|------|
| **机会平等** | 每个人都有进入市场的平等机会 |
| **竞争筛选** | 市场通过竞争识别和奖励有能力者 |
| **进入壁垒低** | 不依赖特权、牌照或血缘关系 |
| **退出机制** | 失败者可以退出并重新开始 |
| **动态效率** | 不断推陈出新，而非保护落后 |

## 与政治贤能制的协同

经济贤能制需要政治贤能制的配合：

- **产权保护**：需要强有力的政治贤能制来执行法律
- **市场秩序**：需要公正的司法体系维护竞争规则
- **长期主义**：需要超越短期选举周期的战略规划

## 突破马尔萨斯陷阱

经济贤能制是西方突破马尔萨斯陷阱的关键机制：

1. **地理大发现** → 欧洲商人发现新大陆
2. **殖民掠夺** → 资本积累加速
3. **工业革命** → 技术进步打破资源约束
4. **市场扩张** → 持续的经济增长成为可能

## 投资启示

经济贤能制对投资的意义：

1. **企业家精神**：关注具有企业家精神的管理层
2. **竞争格局**：只有持续创新的企业才能长期胜出
3. **护城河**：真正的护城河来自不断强化的竞争优势
4. **风险警示**：政府过度干预会削弱经济贤能制的效力
