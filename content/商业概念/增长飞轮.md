## 定义

增长飞轮（Flywheel Effect）是一套**正反馈循环系统**，通常由不少于三个核心环节构成：

1. **追求特定增长结果**：收入、利润、用户量、GMV、估值等
2. **显性需求的抽象"一"**：从用户显性需求中提炼核心驱动力（如用户体验）
3. **隐性供给的关键"一"**：找到驱动需求的底层供给要素（如数据积累），持续把增长结果投入其中

---

## 飞轮的动能变化

```
初期投入 → 积累阈值 → 突破临界点 → 增强效应 → 高速增长
                                              ↓
                               超过极限点（失速点）→ 减速解体
```

飞轮不是永动机——驱动环节性能过剩时，飞轮会减速停摆，需要切换到新的驱动要素。

---

## 经典案例

### 盒马鲜生飞轮
```
用户心智（千人千面） → 更多流量 + 更高效率
        ↑                         ↓
   智能驱动（算法）  ←  数据持续积累
```

- 增长结果：更多流量 + 更高效率
- 显性需求：千人千面的优惠和优选体验
- 隐性驱动：数据积累驱动的智能算法

### 亚马逊飞轮（经典版本）
```
低价+更多选择 → 更好的用户体验 → 更多流量
       ↑                              ↓
   卖家扩展 ← 更低成本结构 ← 规模增大
```

---

## 与S曲线的关系

> 当经营结果持续投入后飞轮动能突破阈值时，就是S曲线穿越破局点之时。

飞轮理论解释了为什么很多伟大企业在早期看起来"不赚钱"——它们在积累飞轮动能，等待突破阈值的那一刻。

---

## 投资视角

飞轮模型是判断**高质量成长企业**的重要工具：

| 分析问题 | 投资含义 |
|---------|---------|
| 公司有没有飞轮？ | 判断是否具备自我强化的增长逻辑 |
| 飞轮现在处于什么阶段？ | 判断当前是蓄力期还是爆发期 |
| 驱动要素会不会失效？ | 判断飞轮的可持续性 |
| 竞争者能否模仿飞轮？ | 判断护城河深度 |

典型案例：茅台的飞轮（品牌稀缺性→社交货币→溢价→品牌价值进一步强化），亚马逊的飞轮（低价→用户→卖家→规模→更低价）。
